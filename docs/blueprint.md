# **App Name**: MailChat

## Core Features:

- Email Authentication: Secure user registration and login via email verification.
- Real-time Messaging: Send and receive text messages instantly.
- Contact List: Maintain a list of contacts with individual chat windows.
- User Profile Management: Basic user profile settings to manage personal information.
- Smart Reply Suggestions: AI tool generates suggested replies based on received messages to allow a quick response.

## Style Guidelines:

- Primary color: Fresh green (#4CAF50), for a clean and modern feel.
- Background color: Off-white (#F0F2F5) to provide a light and airy backdrop.
- Accent color: A slightly darker green (#43A047) for interactive elements and highlights, enhancing usability and drawing user attention.
- Body and headline font: 'PT Sans', a humanist sans-serif to give a modern, approachable feel, suitable for both headlines and body text.
- Use minimalist, vector-based icons for common actions like sending messages, adding contacts, and accessing settings.
- WhatsApp-inspired layout with a contact list on the left and a chat window on the right, optimized for intuitive navigation.
- Subtle transitions and animations when loading messages or switching between chats.
